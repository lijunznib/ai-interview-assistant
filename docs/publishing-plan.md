# 发布计划

目标：将当前快捷键定制版本作为 lijunznib/ai-interview-assistant 发布，并提供可直接安装的 Windows x64 程序。

1. 从现有项目复制版本控制内的代码及回归测试，保留 LICENSE 与上游署名；不复制 .env、截图、依赖、构建产物或用户配置。
2. 更新包名、应用 ID、发布地址和帮助链接；用文件白名单限制安装包内容。
3. 编写中文 README、安装脚本和 Actions。双击 install.cmd 下载正式 Release，验证 SHA256 后启动单击安装器；源码开发仍使用 npm 命令。
4. 验证快捷键测试、类型检查、生产构建、PowerShell 语法、安装包内容，以及真实 GitHub Actions 发布结果。
5. 创建公开仓库，推送源码并发布 v2.2.0；核对正式下载链接和脚本的仅下载模式。

边界：不提交或预填个人密钥，不升级依赖，不承诺跨会议软件的捕获保护；首发支持 Windows x64，保留上游 macOS 源码但不宣称已验证。
